## 方案一：TMDB 榜单扩展（最简单，推荐优先实施）

### 可用榜单
1. **Top Rated 高分榜** `/movie/top_rated`
   - 覆盖：IMDb 和 TMDB 高评分经典电影
   - 优势：质量保证，适合补充经典外语片
   
2. **Now Playing 院线热映** `/movie/now_playing`
   - 覆盖：全球院线正在上映的电影
   - 优势：实时性强，适合跟进新片
   
3. **Upcoming 即将上映** `/movie/upcoming`
   - 覆盖：未来几个月即将上映的电影
   - 优势：提前布局，吸引用户关注

4. **Discover API（高级筛选）** `/discover/movie`
   - 可按条件筛选：
     - 按年份：经典老片（1990s, 1980s, 1970s...）
     - 按地区：日本、韩国、法国、印度、英国...
     - 按类型：动画、纪录片、惊悚、战争...
     - 按评分：vote_average >= 8.0
     - 按投票数：vote_count >= 5000（确保质量）

### 实施策略
**保守策略**（避免影库爆炸）：
- Top Rated: 取前 100 部（每周增量 10 部）
- Now Playing: 取前 20 部（每周刷新）
- Discover 条件筛选：每周轮换不同条件
  - 第 1 周：日本电影 + 评分 >= 7.5
  - 第 2 周：韩国电影 + 评分 >= 7.5
  - 第 3 周：1990s 经典 + 评分 >= 8.0
  - 第 4 周：欧洲电影 + 评分 >= 7.5

**预估增量**：每周新增 30-50 部，一年 1500-2500 部

## 方案二：多数据库整合（复杂度中等）

### 可选数据源
1. **IMDb 非官方 API**
   - 优势：覆盖面最广，评分权威
   - 劣势：官方无 API，需用第三方（OMDb API 或 IMDb-API）
   - 成本：OMDb API 需付费（免费版每天 1000 次）

2. **烂番茄（Rotten Tomatoes）**
   - 优势：专业影评 + 观众评分
   - 劣势：无官方 API，需爬虫（法律风险）

3. **Letterboxd 第三方 API**
   - 优势：文艺片覆盖好，用户品味高
   - 劣势：非官方 API 不稳定

**不推荐**：复杂度高、成本高、法律风险大
